# 2026-09-03

## prd-writer / draft 技能修复（两处）

1. **Token 二次消耗**：原「生成→全文输出会话→确认→全文落盘」会导致章节全文被输出两次（会话展示一次 + 写文件一次），且全文驻留上下文后续每轮重复计费。已改为「生成→直接落盘一次→会话只输出【要点摘要+重点校验表+文件路径】→确认→修改用增量编辑」。改动位置：`draft/SKILL.md` Step 3 执行原则/铁则 + 每一章统一执行模板。

2. **文档内锚点链接无法跳转**：根因有二——(a) 锚点 ID 用了非 ASCII 不换行连字符 U+2011 `‑`（`cap‑xxx`），与引用/渲染 slug 不匹配；(b) draft 技能从未定义锚点「目标」如何渲染（review/testability 技能已有 `<a id="...">` 规范，draft 缺失）。已修复：全局把 U+2011 归一化为 ASCII `-`；在 `draft/policies/writting-rules.md` 新增「锚点定义规范」（显式 `<a id="cap-xxx"></a>`，小写+ASCII 连字符）；并在 SKILL.md Step2/4/5 与模板同步补上锚点目标校验要求。

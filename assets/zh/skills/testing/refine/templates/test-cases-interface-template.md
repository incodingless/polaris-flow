## 3. 设计原则自检

> 与自动化工具的契约：**入参可配置 / 断言明确可量化 / 测试数据可自动清理**。

- [ ] 环境、账号、业务数据已参数化，无硬编码
- [ ] 断言覆盖四层（前三层必备）：状态码 / 业务响应码 / 返回字段与结构 / 数据库落库，非「返回成功即可」
- [ ] 用例执行后不残留脏数据

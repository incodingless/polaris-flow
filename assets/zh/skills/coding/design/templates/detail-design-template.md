> **按需填写**：六个节的标题**必须保留**（主审 S1 逐节校验），但内容按需——不适用或无内容时明确写「无」或「不适用」，不删节、也不为完整而硬凑无意义内容。

> **节名与编号约定**：节名一律中文，与 Step 5.1 主审校验同源；六个必含节的措辞不得改写。

## 各节填充指引

### 1. 实现方案

- **落点**：本变更动了哪些模块 / 类 / 包，谁调谁（不必列出不相关的既有代码）。
- **主成功路径**：用 Mermaid 时序图或流程图描述，图后附「设计意图」与「实现思路」（见「图表要求」）。
- **关键契约**：接口签名、消息 / 数据形状、DDL 片段、状态机、关键条件——**契约级伪码可写**，实现代码不写。
- **无专项时**：数据模型、接口契约等分面细节并入本节；**有专项时**：只写梗概并指向 `## 5` 的索引行，不重复专项内容。

### 2. 边界条件

至少覆盖与主路径相关的失败 / 降级 / 空数据 / 越权 / 并发竞态场景，逐条可判定（触发条件 → 预期行为）。无内容时写「无」。

### 3. 技术风险与缓解

不得只列风险标题；关键路径风险必须有对应缓解，或显式写明「接受 + 理由」。可用表格（风险 / 概率 / 影响 / 缓解）。

### 4. 测试策略

测什么、测到哪一层、关键边界；按需注明「tasks 细化时须补的测试点」（供 tasks 阶段承接）。

### 5. 专项设计索引

未拆专项时写「无」。拆了则逐行给出「专项文件 + 覆盖范围」，且该分面细节不得在本文重复出现。

### 6. Spec Patch 清单

无回写时写「无」。有回写则逐条列出「哪个 spec、补了什么」，并同步改 `specs/*/spec.md`。

## 图表要求

- **必备图**：`## 1. 实现方案` 的主成功路径**至少一张** Mermaid 图（`sequenceDiagram` 或 `flowchart`）；无图即视为实现方案未到可实施粒度。
- **按需图**：`sequenceDiagram`（交互时序）/ `flowchart`（业务逻辑）/ `classDiagram`（类结构）/ `erDiagram`（数据模型）/ `stateDiagram`（状态流转）——只在对应分面确有内容时画，**不得为凑图种硬画**。
- **载体**：图必须是本文档内的 Mermaid 代码块（`mermaid` 围栏）；**禁止**以外部 HTML / PNG / SVG / `.drawio` 作为图表的唯一载体——主审只读文本，外链图等于无图。
- **图的抽象度**：到 C4 的 container 级 + 本次改动的 component 级为止；类图只画本次新增 / 改动的类与关键关系，不画全量类图。
- **图文配合**：先文字后图；每张图后必附两段——**设计意图**（为什么这么设计、解决什么问题）与**实现思路**（关键步骤 / 技术点 / 异常处理）。
- **禁止只有图**：任何图表不得单独存在，必须有配套说明。
- **抽象度口径**：契约级伪码（接口签名、消息形状、DDL）是**必须的**——它们是 build 的直接输入；不写的只是完整实现代码。

## 强制规则

1. **必含节**：`## 1. 实现方案`、`## 2. 边界条件`、`## 3. 技术风险与缓解`、`## 4. 测试策略`、`## 5. 专项设计索引`、`## 6. Spec Patch 清单`——标题原样保留，内容按需（不适用写「无」），缺节 → Step 5.1 主审记 Important
2. **frontmatter**：`change` / `role` / `canonical_spec` 三字段必须齐备且取值正确，不得增删
3. **风险与缓解**：不得只列风险标题；关键路径的风险必须有对应缓解，或显式写明「接受 + 理由」
4. **边界条件**：至少覆盖与主路径相关的失败 / 降级 / 空数据场景，逐条可判定
5. **Spec Patch 清单**：无回写时明确写「无」；有回写则同步改 `specs/*/spec.md`
6. **专项索引**：未拆专项时写「无」；拆了则逐行给出「专项文件 + 覆盖范围」，且该分面细节不得在本文重复出现
7. **深度边界**：只写「怎么实现」，不重述「要什么」（需求归 `specs`）、不重述高层架构结论（归 `design.md`）
8. **图文配合**：每张图后必附「设计意图 + 实现思路」，不得只放图
9. **模板变量**：正文中所有 `{{...}}` 必须在生成时替换为真实值，不得原样留空
10. **主路径图**：`## 1. 实现方案` 无 Mermaid 图承载主成功路径 → Step 5.1 主审按 S3.5 记 Important；图与正文矛盾记 Critical

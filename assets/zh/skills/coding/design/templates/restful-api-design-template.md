## 4. 公共错误码

跨接口复用；按模块分段。接口特有错误码不要写进本表。

### 4.1 认证与授权

| 错误码 | HTTP 状态码 | 业务含义 | 用户提示 |
|--------|-------------|----------|----------|
| UNAUTHORIZED | 401 | Token 无效或缺失 | 请重新登录 |
| FORBIDDEN | 403 | 已认证但权限不足 | 无权限执行该操作 |

### 4.2 资源与数据

| 错误码 | HTTP 状态码 | 业务含义 | 用户提示 |
|--------|-------------|----------|----------|
| NOT_FOUND | 404 | 资源不存在 | 记录不存在 |
| CONFLICT | 409 | 数据冲突 / 版本冲突 | 数据已被他人更新，请刷新后重试 |
| VALIDATION_ERROR | 400 | 参数校验失败 | 请检查输入 |

### 4.3 系统与服务

| 错误码 | HTTP 状态码 | 业务含义 | 用户提示 |
|--------|-------------|----------|----------|
| INTERNAL_ERROR | 500 | 未预期系统错误 | 服务异常，请稍后重试 |
| SERVICE_UNAVAILABLE | 503 | 依赖不可用 | 服务繁忙，请稍后重试 |

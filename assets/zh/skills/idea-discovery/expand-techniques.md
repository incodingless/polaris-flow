# 针对性发散技法

仅当 Phase 1 触发时使用。每个技法必须绑定**具体模糊点**。

## 何时用 / 不用

| 用 | 不用 |
|----|------|
| 模糊点存在 2+ 合理理解 | 已清晰项 |
| 术语多义（如「实时」「协作」） | 用户已给明确约束 |
| 代码与表述矛盾 | 仅为「多聊一会」 |

## 技法

### Spectrum（光谱）

适合：能力级别连续谱（如 presence → cursors → CRDT）。

```
Awareness ── Coordination ── Sync
   │              │            │
 trivial      moderate     complex
```

### 对比表

适合：有限选项（2–3 个），列约束维度。

### 类比

适合：用户熟悉领域；一句话点明差异。

### ASCII 架构草图

适合：流程/状态/依赖；不替代 Phase 5 意图概要。

## 入口示例（裁剪自 openspec-explore）

**模糊想法：** 先 Phase 0 调研，再对**未决点**画 spectrum，问「你更接近哪一段？」

**具体问题：** 先 Read 代码画现状图，问「三处纠缠，先解哪一处？」

**方案对比：** 先问上下文约束，再表格对比；generic 答案禁止。

## 禁止

- Follow interesting threads — 无模糊点绑定的分叉
- Surface 3+ 方向 — 除非该模糊点确有 3+ 合理理解

# 拷问清单（grill-checklist）

源自 grilling 技能扩写。Phase 3 使用；**simple 跳过**。

## 精简版（standard）

逐条覆盖，一次一问，每题含推荐答案：

1. **目的** — 这次变更要达成什么？
2. **范围** — 包含什么 / 明确不包含什么？
3. **验收** — 怎样算完成？
4. **主要风险** — 最可能翻车的一点？

## 完整版（complex）

深度优先遍历设计树：

1. 目标与成功标准
2. 范围与非目标
3. 用户/角色
4. 约束（时间、技术、合规）
5. 依赖与集成点
6. 失败模式与回滚
7. 验收信号（可测量）

## 每题格式

```
**Q:** …
**推荐:** …
**理由:** …
**证据:** （可选，代码/文档路径）
```

## 退出

- 全部覆盖，或
- 剩余标 `OPEN` — 「待 proposal 阶段处理：…」

## 与 Phase 1 交叉验证

「模糊点 X 的结论是否与拷问项 Y 矛盾？」— 矛盾则回 Phase 2。

# Phase 3 — 完整性拷问

## 按复杂度

| 级别 | 范围 |
|------|------|
| simple | **跳过** |
| standard | 精简：目的、范围、验收、主要风险（见 `grill-checklist.md` 精简节） |
| complex | 完整设计树：目标 → 范围 → 角色 → 约束 → 依赖 → 风险 → 验收 |

## 每题格式

**问题** + **推荐答案** + **理由** + （可选）代码库证据

一次一问。能查代码库先查再问。

## 交叉验证

与 Phase 1 模糊点结论对照：「对模糊点 X 的结论是否与 Y 矛盾？」

## 退出

清单覆盖或剩余项标 `OPEN`（待 proposal 处理）。

## 回退

发现矛盾 → 回 Phase 2，不重跑 Phase 0。

完整清单见 `grill-checklist.md`（源自 grilling 技能扩写）。

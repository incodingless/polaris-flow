### 教训：`git commit` 不带路径会**吞掉暂存区里的其它内容**

首次提交时 `git add codereview && git commit -m …`（**无路径参数**）→ 把当时已暂存的 `git mv` 重命名一并提交进 codereview 那个 commit。**没有 push**，已 `git reset 93ac358` 重做。

**规则**：分批提交时，要么**只暂存本次要提交的路径**再 `git commit`（无路径），要么 `git commit -- <paths>`；**不要**在暂存区还留着别的改动时用裸 `git commit`。

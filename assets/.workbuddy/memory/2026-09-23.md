## 工具教训（重要，会重复遇到）

**沙箱内 git 写操作不可用**：

- `.git/index.lock` 能**创建**但 **unlink 被沙箱拦截**（`Operation not permitted`），
  导致 `git add` / `git commit` 报 `index.lock: File exists`。
- 即使只读的 `git status` 也会创建 lock 并留下 stale lock（0 字节），
  下一次写操作就被挡住 —— 现象是「锁文件反复出现且删不掉」。
- **结论**：git 写操作必须用 `dangerouslyDisableSandbox: true`，并在命令前置 `rm -f .git/index.lock`。
- 另：`git commit -F - <<'EOF' … EOF` 的 heredoc 在本 shell 下**静默失败**（无输出、无错误、提交未发生）。
  改用多个 `-m` 参数（每个 `-m` 是一个段落），已验证可用。

**判别方法**：提交后必查 `git log --oneline -3` 确认 HEAD 已前移，不要以「命令无报错」当作成功。

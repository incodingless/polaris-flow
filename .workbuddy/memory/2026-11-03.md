## 构建与测试环境分析（2026-11-03 下午）
- `pnpm build` / `pnpm lint` exit 0；`format:check` 曾挂 3 个 src 文件（`intention-validate.ts` / `git-branch.ts` / `scan-agents.ts`），均已 `prettier --write` 修复，diff 核对为纯格式（换行 / 行宽 / 文件末尾换行），无业务逻辑。
- 全量 vitest：550 项中 503 过 / 47 失败。失败**全部是环境问题**，两类：
  1. 子进程 spawn 失败：WorkBuddy 沙箱的 `node-brokered-fs-shim.cjs` 连不上 `broker.sock`（ECONNREFUSED），报错栈全在 node 内部 + shim，仓库代码根本没执行；

- 结论：**未改任何业务代码**（用户明令）。修复仅限 prettier 格式化。要在真实环境验证测试，须在沙箱外终端复跑 `npx vitest run`。

## Hook 跨平台可执行性调研（只调研，未改代码）

结论：
- Linux/macOS：`bash` + `sh` 系统自带，hook 与 skills 两链均零条件可执行。
- Windows：唯一硬依赖 `bash.exe`（Git for Windows 提供）。关键区分是**两条执行链对 bash 的解析路径不同**：
  - ① 宿主 hook runner 自己起 shell（官方文档：shell form 在 Win 上走 Git Bash，无 Git Bash 则 PowerShell；实测报告有走 cmd.exe 的情形）→ `bash "…/session-start.sh"` 需要 `bash` 在 PATH 上。
  - ② Agent Bash 工具自带 Git Bash，会话内 `bash` 走 `/usr/bin` → 89 处 `bash "$PLUGIN_ROOT/scripts/*.sh"` 不依赖 Windows PATH。
  - 故「会话里 bash 能跑、hook 不跑」不矛盾；doctor 判全局 PATH 比会话内更严，属安全侧。

代码事实：
- 仅一个 hook 事件（SessionStart），命令模板 `bash "${CLAUDE_PLUGIN_ROOT}/hooks/session-start.sh"`（`assets/shared/hooks.json`）。
- 命令改写单源 `src/core/install/hooks.ts:60-63`（`buildPolarisHookCommand`），反斜杠转 `/`，无 `shell` 字段 → 走 shell form。
- 显式 `bash` + 双引号：已避开 Windows 最坑的「裸 `.sh` 路径 → 文件关联 → git-bash.exe（GUI 子系统）→ stdio 丢失 + 弹控制台」陷阱。
- hook 是 skill 的路径注入源（写 `.polaris/.cache/runtime-env` + additionalContext 注入 `PLUGIN_ROOT`）；hook 不跑 → `$PLUGIN_ROOT` 为空 → 89 处脚本调用全断。doctor 缺 bash 只 warn 不阻断。

新发现（本次唯一硬缺陷）：
- `assets/shared/scripts/_polaris-cli.sh:29` `for _f in $(find "$root/hooks" …)` 未加引号 → 路径含空格时自愈全失败 → 仍在 33 行 `exec bash "$self"` 再次命中 CRLF 分支 → **exec 无限递归**，hook 直到超时。触发条件 = CRLF + 插件根路径含空格（Windows 用户目录常见）。修法：`find … -print0 | while IFS= read -r -d ''`。
- 已确认无 `.gitattributes` → Windows 侧 `core.autocrlf=true` 的 clone / 打包会带 CRLF；npm tarball 由 macOS 打包不受影响。

未做/待议：把 hook 命令改成 `node "<root>/hooks/session-start.mjs"`（exec 或 shell form）可彻底去掉 bash 这层依赖，但要先确认 Cursor/Trae 是否支持 `args`/`shell` 字段。

## node 方案（hook 入口去 bash）可行性深挖（午后，未改代码）

- 结论：可行。Cursor 有实证——社区把 .sh hook（走 Git Bash）改成 Node .js hook 解决了 Windows 弹控制台 + 抢焦点；Cursor hook 经 `shellExecService.executeHookDirect` 执行，`node` 是真实 exe，可跑。
- Cursor Windows 已知坑：① 裸 `.sh` 路径 → 文件关联 → "Select an app to open" 弹窗；② hook stdin 可能改由临时文件传递（`session-start` 有 `--fallback-event` 兜底，问题不大）；③ PowerShell bootstrap 与 Git Bash 终端 profile 混用会语法爆炸。
- Trae：hook 支持 `command`（shell 命令），node 应可跑，但有「沙箱 / 本地自动运行」两模式，沙箱可能限制访问全局 CLI 与脚本路径；对 `node` command 的兼容性文档未明示，**需实测**。
- 改动面（只改宿主 hook 入口层，skill 内部 89 处 bash 不动）：
  - 核心逻辑：`hooks.ts` 的 `buildPolarisHookCommand` / `isManagedHookCommand` / `rewriteHookCommand`（正则 `.sh`→`.mjs`）；`hook-assets.ts` 的 `rewritePolarisCliPlatformId`（`@PLATFORM_ID@` 占位移到 `.mjs`）+ `ensureShScriptsExecutable`（hooks 目录 chmod 可去掉，scripts 仍保留）
  - 资产：`hooks.json` command、`session-start.sh`→`session-start.mjs`、hooks/README、scripts/README
  - 测试：15+ 文件断言 `session-start.sh`（hooks-install / skills-install / update-prune / manifest / install-layout / update-fingerprint / session-start-sh.integration 等）
- 待定两点：① shell form（`node "…"`）vs exec form（`node`+`args`）；② `@PLATFORM_ID@` 移法（安装期替换 `.mjs` 文件 vs 读环境变量）。

## publish.sh --force 透传修复（第六批）

- 实测发现 publish.sh 真 bug：`--force` 只放行脚本前置检查，`npm publish` 未传参 → npm 客户端自查 packument 拦下「cannot publish over previously published」，Nexus Allow Redeploy 无从生效（原 L239 注释「覆盖靠 Allow Redeploy，不是 npm 参数」是错的）。
- 修复：`FORCE_ARGS` 显式判断（默认 FORCE="false" 非空，不能用 `${FORCE:+}`，会误展开），`--force` 时透传给 npm publish；两种取值展开已验证。Changelog 追加 Fixed 一条。
- 提醒：透传后能否覆盖仍取决于 Nexus 是否开 Allow Redeploy；没开的话服务端会拒，唯一路径是升版本号。

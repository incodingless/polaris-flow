# 2026-11-08

## Trae 命令布局修复（commandLayout nested → flat）

- 实测问题：Trae 安装后命令触发名为 `/psfl/coding:tweak.md`（嵌套路径推导、带 .md），非预期的 `/psfl:coding:tweak`。
- 根因：trae/trae-cn 未声明 `commandLayout`，默认 nested 的「路径 `/`→`:`」假设是 Claude Code 行为；Trae 官方限定命令名仅支持小写字母/数字/短横线，冒号形态不可实现。
- 修复：trae / trae-cn 声明 `commandLayout: 'flat'`，与 Cursor 同构；落盘 `psfl-coding-tweak.md`，触发 `/psfl-coding-tweak`；`{{CMD_SPR}}` 随布局展开为 `-`，资产文件零改动。
- 改动文件：`src/core/domain/platforms.ts`、`src/core/install/commands.ts`（注释）、`src/core/install/layout.ts`（注释）、`test/ts/commands-install.test.ts`、`CHANGELOG.md`（0.9.0 Fixed 追加）。
- 验证：commands-install / update-fingerprint / install-layout 三文件 24/24 通过；全量 vitest 后台跑卡住被取消，未跑完——提交前需补跑。
- 历史规格文档（docs/superpowers/specs/2026-07-15-platform-install-layout-design.md）的旧说法按惯例不回改。

# 成就大厅（Achievement Hall）UI视觉规范
本规范基于界面截图提取，属于**深色科技游戏化数据仪表盘**风格，核心特征为语义化配色、层级化信息、统一圆角语言、低饱和微质感，适配成就系统、数据看板类产品界面。

## 一、色彩系统
全界面色彩严格服务于信息语义，采用「深色基底+低饱和功能色」体系，无高饱和干扰色，视觉克制且识别性强。

### 1. 背景色阶（由深到浅构建容器层级）
| 色阶层级 | 色彩倾向 | 应用场景 |
| :--- | :--- | :--- |
| 页面基底色 | 极深冷靛蓝黑（带蓝调的近墨色） | 页面最外层全局底色，压低整体视觉重心 |
| 一级卡片背景 | 深靛蓝色（比基底亮1-2个色阶） | 一级功能容器，如任务总览卡片、周期状态卡片 |
| 二级模块背景 | 中深靛蓝/功能色系深色 | 卡片内的数据子模块，按语义匹配对应色系 |
| 描边/分割色 | 极淡同色系亮边 | 卡片边缘微描边、模块隐性分隔线 |

### 2. 功能语义色（核心识别色，与业务含义强绑定）
- **主强调色：低饱和青绿色（Teal）**
  语义：活跃、进行中、增长、正向进度、就绪状态
  应用场景：进度条填充、活跃目标模块、就绪状态标签、在线数据模块、重置时钟卡片
- **完成态色：低饱和暗金棕（褐调）**
  语义：已完成、已结算、沉淀类成就
  应用场景：每日得分卡片、已完成目标模块、已领取奖励模块
- **通用数据色：深青蓝色**
  语义：中性数据、通用统计
  应用场景：终身奖励卡片、通用数值模块、中性数据区块

### 3. 文字色阶
| 色阶 | 亮度表现 | 应用场景 |
| :--- | :--- | :--- |
| 一级文字 | 纯白色 | 页面大标题、卡片主标题、核心数据数值 |
| 二级文字 | 浅灰白色 | 模块子标题、数据分类标签、Tab文字 |
| 三级文字 | 中灰色 | 辅助说明、补充描述、倒计时等次要信息 |

## 二、排版与字体规范
### 1. 字体选型
采用现代无衬线字体（类Inter / SF Pro风格），字形方正简洁；**数字采用等宽字形**，保证多组数据并列时对齐工整，适配数据展示场景。

### 2. 字级与字重层级（视觉权重从高到低）
1. **页面主标题**：大号字 + 粗字重，为页面最高视觉层级
2. **卡片主标题**：中大号字 + 中粗字重，区块核心识别标题
3. **核心数据数值**：中大号字 + 粗字重，数据模块的视觉重心
4. **分类标签**：小号字 + 半粗字重 + 全大写格式，标注数据项分类
5. **正文说明**：常规字号 + 常规字重，描述性说明文本
6. **辅助小字**：极小字号 + 常规字重，补充提示、次要备注信息

### 3. 排版规则
- 所有数据模块统一采用「顶部分类标签 + 中部核心数值 + 底部补充说明」的三段式结构，阅读逻辑自上而下
- 分类标签统一使用全大写格式，强化科技规整感
- 同模块内文字全部左对齐，保持视觉秩序

## 三、布局与容器规范
### 1. 整体布局结构
采用**顶部概览 + Tab导航 + 左右分栏主体**的三段式布局：
- 顶部：3个并列核心数据概览卡片，横向等分排布
- 中部：Tab切换栏，用于切换「每日成就/全局成就」两个维度
- 主体：左宽右窄分栏（比例约2:1）
  - 左侧主内容区：任务总览卡片、在线增长模块、提案生命周期模块
  - 右侧辅助区：周期状态信息卡片

### 2. 统一圆角体系
全界面无直角元素，所有容器、控件、线条均采用圆角处理，风格柔和统一：
- 一级大卡片：大圆角（半径约12-16px），所有一级功能容器通用
- 二级子模块：中圆角（半径约8-12px），卡片内数据块、Tab组件通用
- 三级标签/进度条：小圆角（半径约4-6px），状态标签、进度条两端通用

### 3. 间距规则
- 不同功能模块间距宽松，保证高信息密度下的视觉呼吸感
- 卡片内边距充足，内容不贴边，层级边界清晰
- 同模块内元素间距紧凑，通过间距差异形成自然视觉分组

## 四、核心组件规范
### 1. 顶部数据概览卡片
- 结构：左侧线性图标 + 顶部全大写标签 + 中部核心数值 + 底部说明文本
- 样式：大圆角色块，左对齐排版，图标与文字基线对齐
- 配色：按语义匹配对应功能色的深色底色

### 2. Tab切换组件
- 样式：胶囊式Tab，横向排列
- 状态区分：
  - 激活态：背景稍亮，搭配前置线性图标，文字高亮
  - 未激活态：深色背景，无图标，文字亮度降低
- 无强高亮边框，仅通过背景深浅区分状态，风格克制

### 3. 任务总览卡片
- 结构：顶部标题区 + 右上角完成率模块 + 底部三栏数据子卡片
- 标题区：主标题 + 辅助说明文本，左对齐排布
- 完成率模块：独立圆角方块，顶部标签 + 大号百分比数值 + 底部进度分数
- 底部数据区：三等分并列数据子卡片，分别对应「完成/活跃/收益」三类语义，配色与语义一一对应

### 4. 状态信息卡片
- 结构：顶部状态标题 + 说明文本 + 多行状态项
- 状态项：每行包含状态分类标签 + 状态值，不同状态用背景深浅区分层级
- 右上角附带迷你状态标签，与主状态呼应

### 5. 进度条组件
- 样式：细高条形进度条，两端全圆角
- 结构：顶部分类标注 + 进度轨道 + 进度填充
- 配色：深灰蓝色轨道 + 青绿色填充，填充带有极淡内发光效果
- 两端标注：左侧为进度分类名，右侧为百分比数值

### 6. 状态徽标/标签
- 样式：胶囊形迷你标签，圆角饱满
- 配色：深色底色 + 同色系亮色文字，全程低饱和调性
- 位置：卡片右上角、模块标题左侧，用于标注模块属性或状态
- 分类：状态类（Ready、Capped）、模块分类类（Migrated module、Proposal）

## 五、图标与质感规范
### 1. 图标规范
- 风格：纤细线性图标，线条粗细统一，无填充
- 配色：与同级文字同色，不单独上色
- 作用：仅作语义辅助，不做装饰性放大，始终与文字基线对齐
- 应用场景：Tab前缀、数据卡片前缀、功能入口标识

### 2. 光影与质感
- 整体为**弱层级微质感**设计语言，不靠强投影区分层级，仅通过底色深浅+1px极淡同色系亮边描边构建容器关系
- 无厚重外投影、无强发光效果，所有光影处理极度克制
- 全界面无纹理、无大面积渐变，以纯色块为主要载体，优先保证信息可读性

## 六、核心设计原则
1. **语义优先**：色彩、布局完全服务于信息含义，用户可通过颜色快速识别模块属性
2. **权重分层**：核心数据放大高亮，辅助信息弱化处理，信息层级清晰无干扰
3. **高度统一**：全界面圆角、字体、配色、图标语言高度一致，视觉整体性强
4. **低疲劳度**：低饱和配色+无多余装饰，适合长时间查看的数据面板场景
